# Contributing to GitHub Clone Monitor

Watch the watchers. Alert when people clone your repos.

## Development Setup

```bash
git clone https://github.com/MingYu5/github-clone-monitor.git
cd github-clone-monitor
```

## Contributing

1. Fork the repo
2. Create a feature branch
3. Open PR against `Scottcjn/github-clone-monitor:main`

Questions? Open an issue!
